## 🧮 **LA ECUACIÓN GENERAL - TU BRÚJULA HACIA EL ÉXITO**

```
SCORE_ENARM = ((A × B × C × D × T × V)^(1/Φ)) × 100
```

### **¿Qué significa cada variable en términos prácticos?**

**A = CONOCIMIENTO BASE (Tu % real de aciertos)**
- **Día 1**: 15% → A = 0.15
- **Meta día 180**: 90% → A = 0.90
- **Cómo mejorarlo**: Estudiar teoría 4-5h diarias, leer Manual CTO completo 3 veces

**B = EFICIENCIA DE PRÁCTICA (Qué tan bien distribuyes tu tiempo)**
- **Día 1**: Estudias solo lo que te gusta → B = 0.20
- **Meta día 180**: Estudias exactamente lo que necesitas → B = 0.90
- **Cómo mejorarlo**: Usar sistema de tracking, equilibrar todas las especialidades

**C = CAPACIDAD DIFERENCIACIÓN (Distingues temas parecidos)**
- **Día 1**: Confundes diabetes tipo 1 vs tipo 2 → C = 0.25
- **Meta día 180**: Diferencias 20 tipos de diabetes → C = 0.90
- **Cómo mejorarlo**: Casos clínicos comparativos diarios, tablas de diferenciación

**D = MANEJO DIFICULTAD EXTREMA (Resuelves casos ultra-complejos)**
- **Día 1**: Te bloqueas con casos de 3+ variables → D = 0.10
- **Meta día 180**: Resuelves casos de 10+ variables → D = 0.85
- **Cómo mejorarlo**: Gradualmente aumentar complejidad, casos reales hospitalarios

**T = DETECCIÓN TRAMPAS (Evitas errores tontos)**
- **Día 1**: Caes en "siempre/nunca" → T = 0.15
- **Meta día 180**: Detectas todas las trampas → T = 0.95
- **Cómo mejorarlo**: Entrenamiento anti-trampas 30 min diarios

**V = VELOCIDAD ÓPTIMA (Equilibrio velocidad-precisión)**
- **Día 1**: 3 minutos por pregunta → V = 0.30
- **Meta día 180**: 90 segundos por pregunta → V = 0.90
- **Cómo mejorarlo**: Cronometrar TODAS las preguntas desde día 1

**Φ = GOLDEN RATIO = 1.618** (Constante matemática)

## 🔍 **LOS 7 MÓDULOS EXPLICADOS A DETALLE**

### **MÓDULO 1: ANÁLISIS ERRORES VS ACIERTOS**

**¿Qué hace exactamente?**
El sistema rastrea CADA pregunta que contestas y calcula:

```python
Medicina_Interna: 22% aciertos (45/200) ← CRÍTICO
Cirugía: 12% aciertos (12/100) ← URGENTE  
Ginecología: 16% aciertos (8/50) ← CRÍTICO
```

**Detecta patrones como:**
- Fallas más en mañanas vs tardes
- Tienes "rachas" de errores
- Mejoras/empeoras con tiempo
- Palabras clave que te confunden

**Te dice exactamente:** Dónde estás débil y cuánto debes mejorar cada área.

### **MÓDULO 2: TEMAS MÁS/MENOS VISTOS**

**Ejemplo real:**
```python
SOBREESTUDIADO (desperdicio tiempo):
- Dermatología básica: 200 preguntas → Solo 5% del examen
- Anatomía: 300 preguntas → Solo 3% del examen

SUBESTUDIADO (peligro examen):
- Insuficiencia renal: 10 preguntas → 15% del examen ← PROBLEMA
- Diabetes complicada: 5 preguntas → 12% del examen ← PROBLEMA
```

**Resultado:** Te dice cómo redistribuir tu tiempo para máxima eficiencia.

### **MÓDULO 3: DETECTOR DE SIMILITUDES**

**Ejemplo crítico:**
```
Pregunta A: "Paciente con dolor torácico y disnea..."
Pregunta B: "Paciente con dolor precordial y dificultad respiratoria..."

Similitud: 85% ← PARECIDÍSIMAS

Pero respuesta A: "Infarto agudo miocardio"
Pero respuesta B: "Tromboembolia pulmonar"
```

**El sistema:** Te entrena específicamente en estas diferenciaciones críticas.

### **MÓDULO 4: DIFICULTAD EXTREMA**

**Identifica preguntas "asesinas":**

**Tipo 1 - Pregunta larga (>200 caracteres):**
```
"Paciente masculino de 67 años con antecedente de diabetes mellitus tipo 2 
de 15 años de evolución, hipertensión arterial sistémica de 10 años, 
dislipidemia, tabaquismo de 20 años, con índice de masa corporal de 32, 
que acude por presentar desde hace 3 días dolor precordial opresivo..."
```

**Tipo 2 - Múltiples datos numéricos:**
```
"TA 140/90, FC 95, FR 22, Temp 37.8°C, Hb 11.2, Hto 34%, Leucos 12,500, 
Glucosa 180, Urea 65, Creatinina 1.8, Sodio 135, Potasio 4.2..."
```

**Tipo 3 - Negación doble:**
```
"¿Cuál de las siguientes NO es una contraindicación 
INCORRECTA para el uso de..."
```

**El sistema:** Te entrena gradualmente en estos tipos hasta dominarlos.

### **MÓDULO 5: DETECTOR DE TRAMPAS**

**Los 6 tipos principales con ejemplos:**

**1. Distractor Verdadero pero Irrelevante**
```
Pregunta: "Tratamiento INICIAL para neumonía adquirida en comunidad"
A) Oxígeno suplementario ← Verdadero pero NO es lo MÁS importante
B) Antibióticos ← CORRECTO
C) Broncodilatadores ← Puede ser útil pero no inicial
D) Corticoides ← A veces, pero no inicial
```

**2. Información Extra Confusa**
```
"Paciente 45 años (irrelevante), diabético (relevante), hipertenso (relevante), 
alérgico penicilina (MUY relevante), hermano diabético (irrelevante), 
madre hipertensa (irrelevante), trabaja oficina (irrelevante), 
casado 2 hijos (irrelevante), presenta dolor abdominal (relevante)..."

Solo 4 datos importan de 10 dados.
```

**3. Opciones Parcialmente Correctas**
```
Tratamiento diabetes tipo 2:
A) Solo dieta ← Correcto pero incompleto
B) Dieta + ejercicio ← Más correcto pero aún incompleto  
C) Dieta + ejercicio + metformina ← MÁS CORRECTO ← Respuesta
D) Solo metformina ← Incorrecto
```

**4. Terminología Similar Confusa**
```
A) Insuficiencia cardíaca congestiva
B) Insuficiencia cardíaca descompensada
C) Insuficiencia cardíaca aguda
D) Insuficiencia cardíaca crónica reagudizada

¿Sabes la diferencia exacta? El sistema te enseña.
```
